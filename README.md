# CatCoding Games Hub 🐾🎮
Interactive Cat Games & Behavior Hub

An interactive web application and collection of games designed for cats and cat lovers. Features include:
- Interactive touch-screen cat games (laser chase, mouse hunt, bug catcher)
- Full-screen game overlay with touch-action lock
- Cat behavior and sound enrichment hub
- Cel-shaded editorial card UI

## Play Online
Live demo hosted on GitHub Pages: [https://intzarbaz.github.io/catcoding-games-hub/](https://intzarbaz.github.io/catcoding-games-hub/)
